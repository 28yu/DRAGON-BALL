# 日本語／英語の切り替え（2026-10-08 追加）

## 画面での動き

- ヘッダー右上、明るさ調整ボタンの上に言語の切り替えボタンがある（PCは「English」／「日本語」、スマホは「EN」／「日本」）。
- 押すと、選んだ言語をその端末に覚えて（localStorage の `db-lang`）ページを開き直す。
- 最初に開いたときは端末の言語に合わせる（日本語の端末は日本語、それ以外は英語）。
- URL に `?lang=en` / `?lang=ja` を付けると、その言語で開く（英語のページを人に紹介するとき用）。
- 管理用のダッシュボード（`dashboard.html`）は日本語だけ。

## 仕組み

| 何を | どこで英語にするか |
|---|---|
| 見出し・ボタン・表の項目名など、画面の決まった文言 | `assets/js/*.js` の中で `t("日本語", "English")` と並べて書く。HTML に直接書いた文言は `data-en="English"` 属性 |
| 商品名・説明・メモ・出典名・画像の説明・相場の区分名など、データの文章 | `data/translations/en.json`（日本語の文 → 英訳の対応表）。表示するときに `tx()` で置き換える |
| 日付・金額 | 英語では「Feb 1, 1996」「¥16,500」の形（`common.js` の `formatDate` / `formatYen`） |

- **商品データの原本は今まで通り `data/items.json`（日本語）だけ。** 対応表は翻訳だけを持つ。
- 対応表に英訳がない文は、英語表示でも日本語のまま出る（表示が壊れることはない）。
- 変更履歴（`history`）は画面に出していないので英訳しない。相場の検索語も画面に出ないので英訳しない。

## データを足した・変えたとき

1. `node tools/validate.mjs` を実行すると、英訳がない文の数が警告に出る。
2. `node tools/i18n.mjs --missing` で `data/translations/missing.json`（GitHub には送らない）に一覧ができる。
3. 英訳を `data/translations/en.json` に足す（キーは日本語の文をそのまま。前後の空白は除く）。
4. 元の日本語を書き換えた場合は、古い英訳が使われなくなる。`node tools/i18n.mjs --prune` で使われなくなった英訳を消せる。

## 英訳の決まり（2026-10-08 時点）

- 英訳は Claude が作ったもの（オーナーの確認は未）。事実を足したり省いたりしない。
- ゲームの題名は「ローマ字読み（英語の意味）」の形。例：`Dragon Ball: Shenron no Nazo (Mystery of Shenron)`。
- 主な用語：カードダス＝Carddass、ファミコン＝Famicom、スーパーファミコン＝Super Famicom、ドラゴンボールカプセル＝Dragon Ball Capsule、メガハウス＝MegaHouse、〜編＝… Arc、ボーナスパーツ＝Bonus Part、ヤフオク＝Yahoo! Auctions、メルカリ＝Mercari、駿河屋＝Suruga-ya、ブックオフ＝BOOKOFF、楽天市場＝Rakuten Ichiba、入手先：○○＝Obtained from: ○○。
- 出品名などを引用している所は、日本語の原文を残して英訳を添える。
