# 出品中の一覧（2026-10-08 追加）

集める物（`data/items.json` の商品・フィギュア）のうち、いま出品中の物を集めて一覧にしたページ。

- ページ：https://28yu.github.io/DRAGON-BALL/listings.html （トップのカテゴリーメニューの「🛒 出品中の一覧」、各商品ページの相場の欄の「この商品のいま出品中の物を見る」から入れる）
- データ：`data/listings.json`（`tools/market/listings.mjs` が毎朝、相場の自動取得のあとに上書きする。手で編集しない）

## 取得元

| サイト | 扱い |
|---|---|
| ヤフオク（出品中の検索ページ） | 取得する。Yahoo!フリマの出品も検索結果に含まれるので「Yahoo!フリマ」として分ける。robots.txt で並べ替え・表示件数の指定が禁止されているため付けない（1ページ50件、50件ちょうどなら2ページ目まで） |
| ブックオフ（公式オンラインストア） | 取得する。中古／新品は商品のURLで分かる |
| メルカリ | **自動では取得しない**（公開ページに価格がなく、非公開の仕組みを回避しないと取れない。規約でも自動収集は禁止）。代わりにオーナーが**半自動で取り込む**（下の「メルカリの取り込み」）。一覧の下には商品ごとに「販売中」の検索を開くリンクも出す |
| 楽天市場 | 取得しない（規約で、取得した情報を誰でも見られる場所に保存できないため） |
| 駿河屋 | 取得しない（robots.txt を確認できない） |

- どのサイトも robots.txt を確認し、読み込みの間は3秒あける（`tools/market/lib.mjs`。相場の取得と同じ部品）。
- 出品の写真は保存しない・表示しない（出品者の写真のため）。記録するのは、出品名・価格・即決価格・入札数・終了日時・送料・URL など一覧に出ている文字の情報だけ。
- 相場と同じ条件（`market.mustInclude` / `exclude`）で、関係のない出品・まとめ売りなどを除く。版ごとの検索（`market.variants`。例：完全復刻版）に当てはまった出品は、その版として表示する。

## 絞り込み

- キーワード（出品名・商品名）、カテゴリー、商品、サイト、形式（オークション／即決あり／即決・定価）、状態、価格の範囲、「持っていない物だけ」（初期は ON）、並べ替え（安い順・高い順・終了が近い順・入札が多い順）。
- 状態は一覧に出ないため、出品名の語から機械的に分けた目安。ファミコン・スーファミはカテゴリーの `marketGrades`（未開封・新品／箱付き／箱なし）、書籍・カプセルは「未開封・新品」と「中古・記載なし」。ブックオフは中古／新品。
- 条件は URL に残る（例：`listings.html?cat=famicom&site=yahoo&max=5000`）。

## 注意

- 1日1回の更新なので、すでに売れた・終了した出品も混ざる。終了日時を過ぎたヤフオクの出品は薄く表示し、「終了済みの可能性」と出す。
- 出品名は出品者が書いた日本語のまま表示する（英語表示でも訳さない）。
- 取得元がすべて失敗した日は、前回の一覧を残す。

## メルカリの取り込み（2026-10-08 オーナー指示で追加）

- オーナーが自分のブラウザでメルカリの「販売中」の検索結果を開き、ブックマークレット「DB取り込み」を押す。画面に出ている出品（商品ID・商品名・価格）を読み取り、`dashboard.html#mercari=…` を開く。管理ページでパスワードを入れ、中身を確かめて「保存する」を押すと Supabase（`mercari_listings` 表）に入る。
  - 人が画面を見て写すのと同じ扱いで、ロボットによる自動収集ではない。読み取るのは画面に出ている文字だけで、写真は読まない。
  - 「SOLD」「売り切れ」の出品は読み飛ばす。
  - ブックマークレットの中身は `assets/js/dashboard.js` の `mercariCapture`（URL に入れると改行が消えるため、`//` の注釈を使わず、文の終わりに必ず `;` を付ける）。登録方法は管理ページの「メルカリの出品の取り込み」に書いてある。
  - メルカリの画面の作り（HTML）が変わると読み取れなくなることがある。2026-10-08 時点ではメルカリに似せた練習用ページでしか試せていない（作業環境からメルカリにつながらないため）。
- 保存：`mercari_import`（ログインの鍵が必要）。同じ検索語で前に取り込んだのに今回の画面に無かった出品は、売れた・終わったとみなして一覧から外す（`active=false`。消さない）。最後の取り込みから30日たった出品も表示しない。
- 表示：一覧ページが `mercari_listings` を読み、`assets/js/market-match.js` で商品に当てはめる（条件はヤフオク・ブックオフと同じ。取り込んだ検索語と同じ検索語の商品を優先）。当てはまらない出品は出さない。誰でも見られる（オーナー指示）。
- SQL は `supabase/migrations/20261008_001_mercari_listings.sql`。
